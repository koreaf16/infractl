# InfraCtl 빌드 플랜

## 방향
이 문서는 구현 순서만 남긴 요약본이다. 상세 설계와 구현 세부는 각 `phase*-design.md` 문서에 둔다.

## 구현 순서
| Phase | 목표 | 산출물 |
|---|---|---|
| 1 | 로컬 LLM + bash 실행 | 기본 REPL, 도구 루프 |
| 2 | SSH + 서버 등록 + SQLite | 원격 실행, 서버 저장 |
| 3 | CLI TUI | 화면형 대화 인터페이스 |
| 4 | 서비스 디스커버리 + 커넥터 | DB/WAS 자동 식별 |
| 5 | 안전장치 + 세션/이력 | 확인 단계, 복원, 감사 |
| 6 | 웹 검색 + 학습 도구 + 커스텀 도구 | 외부 지식 연동 |
| 7 | RAG | 벡터 기반 지식 검색 |
| 8 | 고급 기능 | 서브에이전트, 후크, 체크포인트, 스케줄, 비용 |
| 9 | Daemon + Web UI | 브라우저 기반 작업 |
| 10 | 모니터링 | 주기 점검, 로그 감시, 알림, 자동 모드 |

## 공통 기준
- Phase 문서가 상세 설계의 원본이다.
- 상위 문서는 단계 간 관계와 우선순위만 담는다.
- 기능 추가는 가장 가까운 Phase 문서에 흡수한다.

## 최종 구조
Phase 1부터 10까지 순차적으로 확장한다.  
대화형 CLI로 시작해 SSH, TUI, 디스커버리, 안전장치, 지식 연동, RAG, 고급 자동화, Web UI, 모니터링 순으로 완성한다.
