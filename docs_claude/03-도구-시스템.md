# 도구 시스템

## 개요

Claude Code의 도구 시스템은 세 계층으로 구성된다.

```
Tool 인터페이스 (Tool.ts)          ← 추상화 계약
    ↑
tools.ts 레지스트리               ← 전체 도구 목록 관리
    ↑
services/tools/ 실행 엔진         ← 권한 검사 + 실행 + 결과 처리
```

---

## Tool 인터페이스 (Tool.ts)

모든 도구가 구현해야 하는 핵심 타입.

```typescript
type Tool = {
  name: string
  description: string                          // API에 전달되는 설명
  inputSchema: ToolInputJSONSchema             // Zod 기반 입력 스키마
  isEnabled(context?: ...): boolean            // 활성화 조건
  isReadOnly(): boolean                        // 동시 실행 가능 여부
  checkPermissions(input, context): Promise<PermissionResult>  // 권한 검사
  call(input, context, onProgress?): Promise<ToolResult>       // 실제 실행
  renderToolUseMessage?(input, options): React.ReactNode       // UI 렌더링
  renderToolResultMessage?(result, options): React.ReactNode
  renderDoneMessage?(result, options): React.ReactNode
}
```

### ToolUseContext — 도구 실행 컨텍스트

```typescript
type ToolUseContext = {
  options: {
    commands: Command[]
    tools: Tools
    verbose: boolean
    thinkingConfig: ThinkingConfig
    mcpClients: MCPServerConnection[]
    // ...
  }
  abortController: AbortController
  readFileState: FileStateCache          // 파일 LRU 캐시
  getAppState(): AppState
  setAppState(f): void
  setToolJSX?: SetToolJSXFn             // REPL UI 전용
  addNotification?: (n) => void
  appendSystemMessage?: (msg) => void
}
```

### ToolPermissionContext — 권한 컨텍스트

```typescript
type ToolPermissionContext = DeepImmutable<{
  mode: PermissionMode                  // 'default' | 'plan' | 'bypassPermissions' | ...
  additionalWorkingDirectories: Map<string, AdditionalWorkingDirectory>
  alwaysAllowRules: ToolPermissionRulesBySource
  alwaysDenyRules: ToolPermissionRulesBySource
  alwaysAskRules: ToolPermissionRulesBySource
  isBypassPermissionsModeAvailable: boolean
  shouldAvoidPermissionPrompts?: boolean  // 백그라운드 에이전트
}>
```

### 순환 의존성 해결 — Lazy Require

팀 관련 도구들은 순환 의존성을 피하기 위해 lazy require를 사용한다.

```typescript
// 도구가 처음 실제로 필요할 때까지 모듈 로딩 지연
const getTeamCreateTool = () =>
  require('./tools/TeamCreateTool/TeamCreateTool.js').TeamCreateTool

// 사용 시:
if (isAgentSwarmsEnabled()) {
  tools.push(getTeamCreateTool(), getTeamDeleteTool(), getSendMessageTool())
}
```

## 도구 실행 엔진 (services/tools/)

### toolExecution.ts — 단일 도구 실행

`runToolUse(toolUseBlock, context)`가 하나의 도구 호출을 처리한다.

```
runToolUse(block, context)
    │
    ├─ 1. findToolByName() — 도구 찾기
    ├─ 2. tool.checkPermissions() — 권한 검사
    │       ├─ 허용 → 계속
    │       ├─ 거부 → ToolResult(error) 즉시 반환
    │       └─ 질문 필요 → UI 다이얼로그 표시 후 대기
    │
    ├─ 3. 분석 이벤트 로깅 (logEvent)
    ├─ 4. tool.call(input, context, onProgress) — 실제 실행
    │       └─ onProgress → ProgressMessage yield (UI 업데이트)
    │
    └─ 5. ToolResult 반환 (성공/실패/중단)
```

### toolOrchestration.ts — 배치 실행

한 턴에서 여러 도구가 동시에 요청될 때 처리한다.

```
partitionToolCalls(blocks) → [{isConcurrencySafe, blocks}]
    │
    ├─ isConcurrencySafe=true  → runToolsConcurrently() (병렬)
    └─ isConcurrencySafe=false → runToolsSerially()     (직렬)
```

**병렬 실행 후 컨텍스트 모디파이어 순서 보장:**  
병렬로 실행된 도구가 컨텍스트를 변경할 경우, 실행 완료 순서에 관계없이  
원래 순서대로 컨텍스트 변경을 적용한다.

### StreamingToolExecutor.ts — 스트리밍 실행

`StreamingToolExecutor`는 도구 실행 중 진행 상황을 실시간으로 UI에 스트리밍한다.

```typescript
const executor = new StreamingToolExecutor(toolUseContext)
for await (const event of executor.execute(toolUseBlock)) {
  // ProgressMessage, ToolResult 등 순차 수신
}
```

## MCP 도구 통합

MCP 서버가 제공하는 도구는 런타임에 동적으로 추가된다.

```typescript
// main.tsx에서 초기화 시
const { tools: mcpTools } = await getMcpToolsCommandsAndResources(mcpClients)
const allTools = [...getTools(), ...mcpTools]
```

MCP 도구는 `Tool` 인터페이스를 구현한 래퍼로 감싸져,  
내장 도구와 동일한 방식으로 권한 검사 및 실행이 이루어진다.

## 도구 필터링

도구는 컨텍스트에 따라 활성화 여부가 달라진다.

```typescript
// isEnabled() 검사 항목 예시
BashTool.isEnabled() → isNonInteractiveSession이면 false (일부 조건)
AgentTool.isEnabled() → 항상 true
TeamCreateTool.isEnabled() → isAgentSwarmsEnabled()가 true일 때만
```

서브에이전트(AgentTool 내)에서는 허용되지 않는 도구 목록:

```typescript
// constants/tools.ts
ALL_AGENT_DISALLOWED_TOOLS    // 모든 에이전트에서 금지
CUSTOM_AGENT_DISALLOWED_TOOLS // 커스텀 에이전트에서 추가 금지
ASYNC_AGENT_ALLOWED_TOOLS     // 비동기 에이전트에서 허용
```
