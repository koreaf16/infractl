# 도구 상세 구현

## BashTool — 쉘 실행 도구

`tools/BashTool/BashTool.tsx` (161KB)는 가장 복잡한 도구로, 다층 보안 검증 체계를 갖는다.

### 보안 검증 파이프라인

```
BashTool.checkPermissions(command)
    │
    ├─ 1. modeValidation.ts     — 권한 모드 확인 (plan mode에서는 읽기 전용만 허용)
    ├─ 2. bashSecurity.ts       — 위험 패턴 탐지
    │       ├─ 명령 치환: $(), ${}, <>(), >() 차단
    │       ├─ Zsh 위험 명령: zmodload, emulate, sysopen 등
    │       └─ PowerShell 구문 차단 (<#)
    ├─ 3. pathValidation.ts     — 경로 검증 (허용된 디렉토리 내인지)
    ├─ 4. sedValidation.ts      — sed 명령 인라인 편집 검증
    ├─ 5. readOnlyValidation.ts — 읽기 전용 명령 여부 판단
    ├─ 6. bashPermissions.ts    — 권한 규칙 적용 (alwaysAllow/alwaysDeny/alwaysAsk)
    └─ 7. shouldUseSandbox.ts   — 샌드박스 실행 여부 결정
```

### 명령 파싱

```typescript
// utils/bash/ParsedCommand.ts
// 쉘 명령을 구조적으로 파싱해 파이프, 리다이렉션, 서브쉘 등을 분석
const parsed = new ParsedCommand(command)
parsed.baseCommand   // 실제 실행되는 명령어
parsed.args          // 인자 목록
parsed.hasRedirect   // 리다이렉션 여부
```

### Tree-sitter 분석

복잡한 쉘 명령은 tree-sitter 파서로 AST 분석:
- `utils/bash/treeSitterAnalysis.ts` — 구문 트리 분석
- heredoc 탐지, 중첩 명령 치환 탐지 등

### 진행 상황 스트리밍

```typescript
// 실행 중 실시간 출력 스트리밍
onProgress({
  type: 'bash',
  output: stdout,    // 현재까지의 stdout
  isComplete: false,
})
```

## AgentTool — 서브에이전트 도구

`tools/AgentTool/AgentTool.tsx` (235KB)는 독립적인 Claude 인스턴스를 생성해 병렬 실행한다.

### 핵심 실행 흐름

```
AgentTool.call(input, context)
    │
    ├─ loadAgentsDir() — 에이전트 정의 파일(.md) 로드
    ├─ createSubagentContext() — 격리된 실행 컨텍스트 생성
    │       ├─ 새 AbortController (부모와 연결)
    │       ├─ 새 FileStateCache (독립적)
    │       └─ setAppState: 부모의 tasks에만 접근 가능
    │
    ├─ runAgent() — 에이전트 실행 루프
    │       ├─ query() 직접 호출 (QueryEngine 없이)
    │       ├─ 전용 시스템 프롬프트 사용
    │       └─ 도구 필터링 (ALL_AGENT_DISALLOWED_TOOLS 제외)
    │
    └─ LocalAgentTask 등록 → AppState.tasks에 추가
```

### 에이전트 정의 파일

`loadAgentsDir.ts`가 `.claude/agents/` 디렉토리에서 마크다운 파일을 로드한다.

```markdown
---
name: my-agent
model: claude-opus-4-6
tools: [Read, Glob, Grep]
---
# 에이전트 역할 설명...
```

프론트매터로 모델, 허용 도구, 시스템 프롬프트를 지정한다.

### forkSubagent.ts — 프로세스 포크

별도 프로세스로 에이전트를 실행할 때 사용:
- 부모 프로세스와 IPC로 통신
- 더 큰 메모리 격리 제공
- `RemoteAgentTask`로 관리

### built-in 에이전트

`tools/AgentTool/built-in/` 디렉토리에 내장 에이전트 정의 파일들이 있다.

## FileEditTool — 파일 편집 도구

`tools/FileEditTool/`는 정확한 문자열 치환으로 파일을 편집한다.

```typescript
// 입력 스키마
{
  file_path: string,   // 편집할 파일
  old_string: string,  // 찾을 문자열 (정확히 일치해야 함)
  new_string: string,  // 교체할 문자열
  replace_all?: boolean // 전체 치환 여부
}
```

**고유성 검증:** `old_string`이 파일 내에서 정확히 한 번 등장해야 한다.  
중복 시 오류를 반환하며, 더 넓은 컨텍스트를 포함하도록 유도한다.

## FileReadTool — 파일 읽기 도구

`tools/FileReadTool/`는 파일을 읽어 줄 번호와 함께 반환한다.

- `limit`, `offset` 파라미터로 대형 파일 부분 읽기
- 이미지 파일은 base64로 인코딩해 반환 (multimodal)
- PDF는 페이지 범위 지정 가능
- Jupyter 노트북(`.ipynb`)은 셀 + 출력 함께 표시

## GlobTool / GrepTool — 검색 도구

### GlobTool

파일 경로 패턴 매칭. 내부적으로 `fast-glob` 라이브러리 사용.

```typescript
{ pattern: "**/*.tsx", path: "/src" }
// → 수정 시간 순 정렬된 파일 경로 목록
```

### GrepTool

파일 내용 검색. `ripgrep`을 외부 프로세스로 실행한다.

```typescript
{
  pattern: "QueryEngine",  // 정규식
  glob: "*.ts",            // 파일 필터
  output_mode: "content",  // 'content' | 'files_with_matches' | 'count'
  context: 2               // 주변 라인 수
}
```

## AgentTool 관련 특수 도구

### TeamCreateTool / TeamDeleteTool / SendMessageTool

멀티에이전트 협업에서 팀을 구성하고 메시지를 전달하는 도구.

```typescript
// TeamCreateTool: 새 팀메이트(InProcessTeammateTask) 생성
TeamCreateTool.call({ name: "reviewer", prompt: "..." })

// SendMessageTool: 이름으로 팀메이트에게 메시지 전달
SendMessageTool.call({ to: "reviewer", message: "파일 검토 부탁해" })
// agentNameRegistry에서 name → AgentId 조회 후 메일박스에 전달
```

## TaskCreateTool / TaskStopTool / TaskOutputTool

백그라운드 태스크를 관리하는 도구들.

```typescript
// TaskCreateTool: 백그라운드 Bash 태스크 생성
TaskCreateTool.call({
  command: "npm test",
  description: "테스트 실행",
  timeout: 60000,
})
// → taskId 반환

// TaskOutputTool: 태스크 출력 스트리밍 조회
TaskOutputTool.call({ task_id: "b3f2a1..." })
// → 누적 stdout/stderr, status

// TaskStopTool: 실행 중인 태스크 종료
TaskStopTool.call({ task_id: "b3f2a1..." })
```

## EnterPlanModeTool / ExitPlanModeV2Tool

계획 수립 모드를 제어하는 도구.

```typescript
// EnterPlanModeTool: 계획 모드 진입
// → PermissionMode를 'plan'으로 변경
// → Bash 도구가 읽기 전용으로만 동작

// ExitPlanModeV2Tool: 계획 모드 종료 + 계획 승인
ExitPlanModeV2Tool.call({ plan: "수행할 작업 목록..." })
// → 사용자에게 계획을 보여주고 승인 요청
// → 승인 시 'default' 모드로 복귀
```

## ToolSearchTool — 지연 도구 탐색

`tools/ToolSearchTool/`는 사용 빈도가 낮은 도구들을 처음 필요할 때만 로드한다.

```typescript
// 도구 목록에 포함되지 않은 도구를 키워드로 검색
ToolSearchTool.call({ query: "google calendar" })
// → 매칭되는 deferred 도구의 스키마를 반환
// → Claude가 해당 도구를 즉시 사용할 수 있게 됨
```
