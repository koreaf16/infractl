# 플러그인과 스킬

## 개요

| 구분 | 목적 | 위치 |
|------|------|------|
| **스킬** | 슬래시 커맨드 형태의 재사용 가능한 프롬프트/작업 | `.claude/skills/` 또는 `~/.claude/skills/` |
| **플러그인** | MCP 서버 + 스킬 + 설정의 패키지 묶음 | `~/.claude/plugins/` |

---

## 스킬 시스템

### 스킬 파일 구조

스킬은 마크다운 파일로 정의된다. 파일명이 슬래시 커맨드가 된다.

```markdown
---
description: 커밋 메시지 생성 및 커밋 실행
model: claude-sonnet-4-6
tools: [Bash, Read]
effort: high
hooks:
  PostToolUse:
    - matcher: Bash
      command: echo "커밋 완료"
---

# Commit 스킬

다음 단계를 수행해주세요:
1. git diff --staged로 변경 내용 확인
2. Conventional Commits 형식으로 커밋 메시지 작성
3. git commit 실행
```

### 프론트매터 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `description` | string | 스킬 설명 |
| `model` | string | 사용할 모델 (오버라이드) |
| `tools` | string[] | 허용할 도구 목록 |
| `effort` | `low\|medium\|high` | 작업 복잡도 힌트 |
| `hooks` | HookConfig | 훅 설정 |
| `arguments` | string[] | 스킬 인자 정의 |
| `allowed_tools` | string[] | tools와 동일 (호환성) |

### 스킬 탐색 순서

`skills/loadSkillsDir.ts`가 여러 위치에서 스킬을 로드한다.

```
1. 번들 스킬 (skills/bundled/) — 내장 스킬
2. 사용자 스킬 (~/.claude/skills/)
3. 프로젝트 스킬 (.claude/skills/) — git root까지 탐색
4. 추가 디렉토리 (--add-dir 플래그로 지정)
```

같은 이름의 스킬이 여러 위치에 있으면 **가장 나중에 로드된 것**이 우선한다.

### 스킬 슬래시 커맨드화

로드된 스킬은 `PromptCommand` 타입으로 변환되어 슬래시 커맨드 레지스트리에 등록된다.

```typescript
type PromptCommand = {
  type: 'prompt'
  name: string           // 파일명 (확장자 제외)
  description: string
  prompt: string         // 마크다운 내용
  tools?: string[]
  model?: string
  // ...
}
```

### 스킬 실행 (SkillTool)

스킬은 `SkillTool`을 통해 도구로도 실행할 수 있다.

```typescript
// SkillTool은 스킬 이름을 받아 해당 스킬의 프롬프트를 Claude에게 주입
SkillTool.call({ skill_name: 'commit', arguments: {} })
// → 스킬 프롬프트를 user 메시지로 변환해 쿼리 루프에 주입
```

## 플러그인 시스템

### 플러그인 구조

```json
// ~/.claude/plugins/my-plugin/manifest.json
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "내 커스텀 플러그인",
  "mcpServers": {
    "my-server": {
      "command": "node",
      "args": ["server.js"]
    }
  },
  "skills": ["./skills/"],
  "settings": {
    "defaultModel": "claude-sonnet-4-6"
  }
}
```

### 플러그인 로딩

`utils/plugins/pluginLoader.ts`가 플러그인 디렉토리를 탐색한다.

```
loadAllPlugins()
    │
    ├─ 플러그인 디렉토리 탐색 (~/.claude/plugins/)
    ├─ manifest.json 파싱 및 검증
    ├─ MCP 서버 설정 추출 → MCP 클라이언트에 추가
    ├─ 스킬 디렉토리 로드
    └─ AppState.plugins에 등록
```

### 내장 플러그인 (bundledPlugins)

`plugins/bundled/`에 내장된 플러그인들:

```typescript
// plugins/builtinPlugins.ts
// 번들된 플러그인 초기화
initBuiltinPlugins()
// → 내장 MCP 서버, 스킬 등 등록
```

### 플러그인 상태

```typescript
// AppState.plugins
{
  enabled: LoadedPlugin[]          // 활성화된 플러그인
  disabled: LoadedPlugin[]         // 비활성화된 플러그인
  commands: Command[]              // 플러그인이 추가한 커맨드
  errors: PluginError[]            // 로딩 오류
  installationStatus: {...}        // 설치 상태 추적
  needsRefresh: boolean            // 재로드 필요 여부
}
```

### 플러그인 관리 커맨드

`/plugin` 슬래시 커맨드로 런타임에 플러그인을 관리한다.

```
/plugin list          → 설치된 플러그인 목록
/plugin install <url> → 플러그인 설치
/plugin enable <name> → 플러그인 활성화
/plugin disable <name>→ 플러그인 비활성화
/reload-plugins       → 플러그인 상태 재로드
```

## 번들 스킬

`skills/bundled/`에 내장된 기본 스킬들:

```typescript
// skills/bundled/index.ts
initBundledSkills()
// → 내장 스킬들을 레지스트리에 등록
```

내장 스킬 예시:
- `commit` — git 커밋 자동화
- `review-pr` — PR 코드 리뷰
- `update-config` — Claude Code 설정 변경
