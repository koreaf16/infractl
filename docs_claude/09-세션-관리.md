# 세션 관리

## 개요

Claude Code는 대화 히스토리를 디스크에 저장해 재개(resume)할 수 있으며,  
컨텍스트 창이 가득 차면 자동으로 압축(compact)해 대화를 이어간다.

---

## 세션 저장 (sessionStorage.ts)

`utils/sessionStorage.ts` (185KB)는 세션 전체 생명주기를 담당하는 핵심 모듈이다.

### 저장 위치

```
~/.claude/projects/<projectPath>/
    <sessionId>.jsonl          ← 대화 트랜스크립트 (JSONL 형식)
    <sessionId>-agent-<n>.jsonl ← 서브에이전트 트랜스크립트
```

### 트랜스크립트 형식

각 라인은 `Entry` 타입의 JSON 객체:

```typescript
type Entry =
  | TranscriptMessage       // 대화 메시지 (user/assistant/system)
  | FileHistorySnapshotMessage  // 파일 변경 스냅샷
  | AttributionSnapshotMessage  // git blame 정보
  | ContentReplacementEntry // 도구 결과 교체 기록
  | ContextCollapseSnapshotEntry // 컨텍스트 접기 스냅샷
```

### 핵심 함수

```typescript
// 메시지를 디스크에 기록
recordTranscript(message, sessionId)

// 세션 완전 저장 (flush)
flushSessionStorage(sessionId)

// 프로젝트 디렉토리 경로
getProjectDir(cwd)  // ~/.claude/projects/인코딩된경로/

// 에이전트 트랜스크립트 경로
getAgentTranscriptPath(sessionId, agentIndex)
```

## 세션 복원 (conversationRecovery.ts)

`/resume` 명령이나 `--resume` 플래그로 이전 세션을 재개한다.

```typescript
// 복원 흐름
loadConversationForResume(sessionId)
    │
    ├─ JSONL 파일 읽기
    ├─ 메시지 역직렬화 (Message 타입으로 복원)
    ├─ compact 경계 이후 메시지만 선택 (getMessagesAfterCompactBoundary)
    └─ QueryEngine에 initialMessages로 주입
```

`switchSession()`은 `bootstrap/state.ts`의 `sessionId`를 교체해  
새로운 세션 ID로 전환한다.

## 자동 컴팩트 (autoCompact.ts)

컨텍스트 창이 한계에 가까워지면 자동으로 대화를 압축한다.

### 토큰 경고 상태

```typescript
// 유효 컨텍스트 창 = 모델 컨텍스트 창 - 최대 출력 토큰 (20,000 예약)
getEffectiveContextWindowSize(model)

// 사용량 비율에 따른 상태 분류
calculateTokenWarningState(usedTokens, maxTokens)
// → 'ok' | 'warning' | 'critical' | 'overflow'
```

| 상태 | 의미 | 조치 |
|------|------|------|
| `ok` | 정상 | 없음 |
| `warning` | 80% 초과 | UI 경고 표시 |
| `critical` | 95% 초과 | 컴팩트 트리거 |
| `overflow` | 100% 초과 | 즉시 컴팩트 (또는 오류) |

### AutoCompactTrackingState

```typescript
type AutoCompactTrackingState = {
  compacted: boolean
  turnCounter: number
  turnId: string              // 턴별 고유 ID
  consecutiveFailures?: number // 연속 실패 카운터 (회로 차단기)
}
```

연속 실패가 일정 횟수를 초과하면 컴팩트 재시도를 중단한다.  
(컨텍스트가 복구 불가능하게 초과된 경우 무한 루프 방지)

## 수동 컴팩트 (compact.ts)

`/compact` 명령이나 컴팩트 경계 도달 시 실행된다.

```typescript
// services/compact/compact.ts
compactConversation(messages, context)
    │
    ├─ Claude API 호출 → "대화 요약 생성"
    ├─ SystemCompactBoundaryMessage 삽입
    └─ 이후 쿼리에서 getMessagesAfterCompactBoundary()로 경계 이후만 사용
```

**컴팩트 경계 메시지:**

```typescript
type SystemCompactBoundaryMessage = {
  type: 'system'
  subtype: 'compact_boundary'
  summary: string   // API가 생성한 대화 요약
  timestamp: number
}
```

컴팩트 후 `summary`가 시스템 메시지로 주입되어 이전 대화 맥락을 유지한다.

## 마이크로 컴팩트 (microCompact.ts)

도구 결과가 너무 클 때 해당 결과만 요약하는 경량 컴팩트.

```typescript
// 도구 결과가 MAX_TOOL_RESULT_TOKENS를 초과하면
// 전체 대화 컴팩트 대신 해당 결과만 축약
microCompact(toolResult)
// → 원본 대신 요약된 결과를 API에 전송
```

## 파일 히스토리 (fileHistory.ts)

도구가 파일을 변경할 때마다 스냅샷을 저장한다.

```typescript
// 변경 전 스냅샷 저장
fileHistoryMakeSnapshot(filePath, fileStateCache)

// 히스토리 조회
type FileHistoryState = {
  snapshots: Map<string, FileSnapshot>
  enabled: boolean
}
```

`/diff` 명령이나 git commit attribution에 활용된다.

## 세션 식별 체계

```typescript
asSessionId(crypto.randomUUID())
asAgentId(crypto.randomUUID())
```
