# UI 렌더링

## 개요

Claude Code의 UI는 React와 Ink (터미널 렌더러)로 구현된다.  
일반 React와 동일한 컴포넌트 모델이지만, DOM 대신 터미널에 렌더링된다.

---

## 렌더링 스택

```
React 컴포넌트
    ↓
Ink (react-ink)      ← 터미널 레이아웃 엔진
    ↓
Yoga (flexbox)       ← 레이아웃 계산 (native-ts/yoga-layout)
    ↓
터미널 stdout
```

```typescript
// screens/REPL.tsx

```

## 컴포넌트 구조

```
App.tsx
└── REPL.tsx
    ├── VirtualMessageList.tsx     ← 가상 스크롤 메시지 목록
    │   └── Message.tsx
    │       ├── AssistantMessage 컴포넌트
    │       │   ├── TextBlock (마크다운 렌더링)
    │       │   └── ToolUse 컴포넌트들
    │       ├── UserMessage 컴포넌트
    │       └── SystemMessage 컴포넌트
    │
    ├── PromptInput/               ← 입력 영역
    │   ├── TextInput
    │   ├── PromptInputFooter      ← 하단 필 (태스크, 팀, Bridge 등)
    │   └── PermissionDialog       ← 권한 요청 다이얼로그
    │
    └── StatusLine.tsx             ← 상단 상태바
```

## 메시지 렌더링 (components/messages/)

각 메시지 타입별 전용 컴포넌트:

| 메시지 타입 | 컴포넌트 |
|------------|---------|
| AssistantMessage | 텍스트 + ToolUse 블록 |
| UserMessage | 사용자 입력 텍스트 |
| ProgressMessage | 도구 실행 중 진행 표시 |
| ToolUseSummaryMessage | 도구 사용 요약 |
| SystemMessage | 시스템 알림 (오류, 컴팩트 등) |
| AttachmentMessage | 메모리 파일 첨부 |
| TombstoneMessage | 삭제된 메시지 플레이스홀더 |

### 도구별 진행 표시

```typescript
// types/tools.ts
type BashProgress = { type: 'bash'; output: string; isComplete: boolean }
type AgentToolProgress = { type: 'agent'; ... }
type REPLToolProgress = { type: 'repl'; ... }
type MCPProgress = { type: 'mcp'; ... }
type WebSearchProgress = { type: 'web_search'; ... }
```

## 디자인 시스템 (components/design-system/)

재사용 가능한 UI 기본 요소들:

```
Dialog.tsx         ← 모달 다이얼로그
Tabs.tsx           ← 탭 UI
ThemeProvider.tsx  ← 테마 (색상) 컨텍스트
Spinner.tsx        ← 로딩 스피너
Box/Text           ← Ink 기본 요소 래퍼
```

### 테마 시스템

```typescript
// utils/theme.ts
type Theme = {
  text: string          // 기본 텍스트 색상
  planMode: string      // 계획 모드 강조색
  permission: string    // 권한 요청 색상
  autoAccept: string    // 자동 수락 색상
  error: string         // 오류 색상
  // ...
}

// 기본 테마 + 사용자 커스텀 테마
```

## interactiveHelpers.tsx

반복적으로 사용되는 렌더링 유틸리티.

```typescript
renderAndRun(component, options)  // Ink 렌더링 시작
showSetupScreens(...)             // 설정 화면 표시
exitWithError(msg)                // 오류 출력 후 종료
exitWithMessage(msg)              // 메시지 출력 후 종료
getRenderContext()                // 현재 렌더링 컨텍스트
```
