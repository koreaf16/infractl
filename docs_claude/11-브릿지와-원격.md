# 브릿지와 원격 세션

## 개요

Bridge 시스템은 로컬의 Claude Code CLI를 claude.ai 웹 인터페이스 또는 다른 클라이언트와 실시간으로 연결한다.

```
로컬 Claude Code CLI
    │ Bridge 프로토콜 (WebSocket/HTTP Polling)
    ▼
Claude Bridge 서버 (Anthropic 인프라)
    │
    ▼
claude.ai 웹 브라우저 (또는 다른 클라이언트)
```

---

## Bridge 모드 유형

### Always-On Bridge (ReplBridge)

`bridge/replBridge.ts` (102KB) — `/remote-control` 또는 `/config`로 활성화.

```typescript
// AppState에서 Bridge 상태 추적
replBridgeEnabled: boolean          // 활성화 여부 (설정)
replBridgeConnected: boolean        // Ready 상태 (환경 등록 완료)
replBridgeSessionActive: boolean    // 사용자 연결됨 (WebSocket 열림)
replBridgeReconnecting: boolean     // 재연결 중 (오류 백오프)
replBridgeConnectUrl: string        // 연결 URL (?bridge=envId)
replBridgeSessionUrl: string        // 세션 URL (claude.ai/...)
```

**연결 흐름:**

```
/remote-control 실행
    │
    ├─ createBridgeApiClient() — HTTP 클라이언트 생성
    ├─ registerWorker()         — 환경 ID 등록 (서버에 등록)
    ├─ pollConfig() 루프        — 세션 요청 대기
    │
    └─ 사용자가 URL로 접속 시:
            ├─ SessionSpawner → 새 Claude 세션 포크
            └─ WebSocket 연결 → 실시간 메시지 스트리밍
```

## 원격 세션 관리 (remote/)

`remote/RemoteSessionManager.ts`는 원격 Claude 세션 뷰어를 관리한다.

```typescript
// claude assistant 뷰어 모드:
// → 원격 daemon의 세션을 로컬에서 관찰
// remote/SessionsWebSocket.ts
// → WebSocket으로 원격 세션 이벤트 수신
// → AppState.remoteConnectionStatus 업데이트
```

**원격 세션 상태:**

```typescript
remoteConnectionStatus:
  | 'connecting'    // 초기 연결 중
  | 'connected'     // 이벤트 스트림 열림
  | 'reconnecting'  // WebSocket 재연결 중 (백오프)
  | 'disconnected'  // 영구 종료

remoteBackgroundTaskCount: number
// 원격 daemon의 백그라운드 태스크 수
// (로컬 AppState.tasks는 비어있음 — 원격 프로세스에 있음)
```

## SDK 모드 (entrypoints/sdk/)

프로그래밍 방식으로 Claude Code를 사용할 때의 진입점.

```typescript
// entrypoints/sdk/coreSchemas.ts
// 입출력 스키마 정의 (SDKMessage, SDKStatus 등)

type SDKMessage =
  | { type: 'assistant'; message: AssistantMessage }
  | { type: 'user'; message: UserMessage }
  | { type: 'result'; result: string; usage: Usage }
  | SDKStatus
  | SDKPermissionDenial
  | SDKCompactBoundaryMessage
```

**SDK 사용 패턴:**

```typescript
// QueryEngine을 직접 사용
const engine = new QueryEngine(config)
for await (const msg of engine.submitMessage("파일을 분석해줘")) {
  if (msg.type === 'assistant') {
    // 스트리밍 텍스트 처리
  }
  if (msg.type === 'result') {
    // 최종 결과
    break
  }
}
```
