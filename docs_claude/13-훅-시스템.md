# 훅 시스템

## 개요

훅(Hook)은 Claude Code의 핵심 이벤트에 사용자 정의 쉘 명령이나 함수를 연결하는 확장 메커니즘이다.  
`settings.json`에 설정하며, 하네스(harness)가 실행한다.

---

## 훅 이벤트 종류

`src/entrypoints/agentSdkTypes.ts`의 `HOOK_EVENTS`:

| 이벤트 | 트리거 시점 |
|--------|-------------|
| `PreToolUse` | 도구 실행 직전 |
| `PostToolUse` | 도구 실행 완료 후 |
| `Notification` | OS 알림 발송 시 |
| `Stop` | Claude 응답 완료 시 |
| `SubagentStop` | 서브에이전트 응답 완료 시 |
| `PreCompact` | 컴팩트 실행 전 |
| `PostCompact` | 컴팩트 완료 후 |
| `SessionStart` | 세션 시작 시 |

## 훅 타입

```typescript
// schemas/hooks.ts에서 Zod로 검증

// 1. Command 훅 — 쉘 명령 실행
{
  type: 'command',
  command: 'npm test',        // 실행할 쉘 명령
  if: 'Bash(git *)',          // 조건 필터 (권한 규칙 구문)
  shell: 'bash' | 'powershell',
  timeout: 30,                // 초 단위 타임아웃
  statusMessage: '테스트 중...',
  once: true,                 // 한 번 실행 후 제거
  async: false,               // true면 백그라운드 실행 (비블로킹)
}

// 2. HTTP 훅 — HTTP 엔드포인트 호출
{
  type: 'http',
  url: 'https://my-server.com/hook',
  method: 'POST',
  headers: { 'Authorization': 'Bearer ...' },
  timeout: 10,
}

// 3. Agent 훅 — Claude 에이전트 호출
{
  type: 'agent',
  agent: 'my-agent-name',
  prompt: '현재 작업을 검토해줘',
  timeout: 60,
}

// 4. Function 훅 — 코드 내 등록 (세션 범위, 설정 불가)
{
  type: 'function',
  callback: async (messages, signal) => boolean,
  errorMessage: '검증 실패',
}
```

### 조건 필터 (`if` 필드)

권한 규칙 구문으로 특정 도구 호출에만 훅을 실행한다.

```
if: "Bash(git *)"        → git으로 시작하는 Bash 명령에만
if: "Write(*.ts)"        → TypeScript 파일 쓰기에만
if: "Read"               → 모든 Read 도구 호출에
```

## 설정 방법 (settings.json)

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "echo '도구 실행 전: $CLAUDE_TOOL_INPUT'",
            "if": "Bash(rm *)"
          }
        ]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Write",
        "hooks": [
          {
            "type": "command",
            "command": "npx prettier --write $CLAUDE_TOOL_INPUT_FILE_PATH"
          }
        ]
      }
    ]
  }
}
```

**matcher:** 도구 이름 또는 MCP 서버 이름 (`mcp__server__tool`)

## 훅 실행 흐름

```
도구 실행 전 (PreToolUse)
    │
    ├─ executePermissionDeniedHooks()  ← 권한 거부 시
    └─ executePreToolUseHooks()        ← 정상 실행 전
            │
            ├─ settings.json 훅 + 세션 훅 매칭
            ├─ if 조건 검사
            └─ 훅 실행:
                ├─ command → execCommandHook() (서브프로세스)
                ├─ http    → execHttpHook()     (fetch)
                ├─ agent   → execAgentHook()    (Claude 호출)
                └─ function → callback()

도구 실행 후 (PostToolUse)
    └─ executePostToolUseHooks()       ← 결과와 함께 실행
```

### 환경변수로 컨텍스트 전달

훅 command에서 다음 환경변수 사용 가능:

```
CLAUDE_TOOL_NAME          = "Bash"
CLAUDE_TOOL_INPUT         = '{"command":"ls -la"}'
CLAUDE_TOOL_RESULT        = '{"stdout":"...","exitCode":0}'
CLAUDE_SESSION_ID         = "uuid..."
CLAUDE_TOOL_INPUT_FILE_PATH = "/path/to/file.ts"  (파일 도구 전용)
```

## 세션 훅 (SessionHooksState)

`utils/hooks/sessionHooks.ts`는 코드에서 동적으로 등록하는 훅을 관리한다.

```typescript
type SessionStore = {
  hooks: {
    [event in HookEvent]?: SessionHookMatcher[]
  }
}

// 세션 훅 = Map<sessionId, SessionStore>
// Map을 사용하므로 .set()이 O(1), 리스너 불필요
type SessionHooksState = Map<string, SessionStore>
```

**세션 훅 특성:**
- 설정 파일에 저장되지 않음 (메모리 전용)
- 세션 종료 시 자동 제거
- `FunctionHook` 타입만 지원 (직렬화 불가)

스킬 파일의 프론트매터에서 훅을 등록할 수 있다:

```markdown
---
hooks:
  PostToolUse:
    - matcher: Write
      command: prettier --write $CLAUDE_TOOL_INPUT_FILE_PATH
---
```

## 훅 설정 스냅샷

`utils/hooks/hooksConfigSnapshot.ts`는 세션 시작 시 훅 설정의 스냅샷을 캡처한다.

```typescript
captureHooksConfigSnapshot()  // setup() 시 실행
updateHooksConfigSnapshot()   // 설정 변경 시 업데이트
```

세션 중에 `settings.json`이 변경되면 경고를 표시한다.

## SSRF 방어 (ssrfGuard.ts)

HTTP 훅 실행 시 내부 네트워크 접근을 방지한다.

```typescript
// utils/hooks/ssrfGuard.ts
// 로컬호스트, 프라이빗 IP, 메타데이터 서비스 등 차단
validateHookUrl(url)
// → 허용되지 않은 URL이면 오류 발생
```

## PostSampling 훅 (postSamplingHooks.ts)

API 응답 후 실행되는 특수 훅. `query.ts`에서 직접 호출된다.

```typescript
// utils/hooks/postSamplingHooks.ts
executePostSamplingHooks(messages, context)
// → Stop 이벤트 훅 실행
// → 구조화 출력 강제 적용
```
