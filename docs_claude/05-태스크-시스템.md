# 태스크 시스템

## 개요

태스크 시스템은 백그라운드에서 실행되는 작업들을 관리한다.  
메인 대화 루프와 독립적으로 실행되며, `AppState.tasks`에 상태가 저장된다.

---

## TaskType — 태스크 유형

```typescript
type TaskType =
  | 'local_bash'          // 로컬 쉘 명령 실행 (TaskCreateTool)
  | 'local_agent'         // 로컬 에이전트 실행 (AgentTool)
  | 'remote_agent'        // 원격 에이전트 실행 (forkSubagent)
  | 'in_process_teammate' // 인프로세스 팀메이트 (TeamCreateTool)
  | 'local_workflow'      // 워크플로우 실행 (WorkflowTool)
  | 'monitor_mcp'         // MCP 서버 모니터링
  | 'dream'               // 자동 메모리 통합 (백그라운드)
```

---

## TaskStatus — 상태 머신

```
pending → running → completed
                  → failed
                  → killed
```

```typescript
type TaskStatus = 'pending' | 'running' | 'completed' | 'failed' | 'killed'

// 터미널 상태 판별
function isTerminalTaskStatus(status: TaskStatus): boolean {
  return status === 'completed' || status === 'failed' || status === 'killed'
}
```

터미널 상태에 도달한 태스크는 더 이상 메시지를 수신하지 않으며,  
일정 시간(`PANEL_GRACE_MS`) 후 AppState에서 제거된다.

---

## TaskStateBase — 공통 상태 필드

```typescript
type TaskStateBase = {
  id: string          // prefix + 8자 (예: 'a3f2a1b2') — 36진수 랜덤
  type: TaskType
  status: TaskStatus
  description: string
  toolUseId?: string  // 생성한 도구 사용 블록 ID
  startTime: number   // Unix 타임스탬프 (ms)
  endTime?: number
  totalPausedMs?: number
  outputFile: string  // 디스크 출력 파일 경로
  outputOffset: number // 마지막 읽은 오프셋
  notified: boolean   // 완료 알림 전송 여부
}
```

### 태스크 ID 체계

```
prefix + 8자 랜덤 문자 (36진수: 0-9, a-z)
  'b' → local_bash
  'a' → local_agent
  'r' → remote_agent
  't' → in_process_teammate
  'w' → local_workflow
  'm' → monitor_mcp
  'd' → dream
```

예: `a3f2a1b2` = `local_agent` 태스크

## LocalShellTask — 쉘 실행 태스크

`tasks/LocalShellTask/`는 `TaskCreateTool`이 생성하는 백그라운드 Bash 실행이다.

**생성 과정:**
1. `TaskCreateTool.call({ command, description, timeout })`
2. `LocalShellTask.spawn()` → 새 쉘 프로세스 생성
3. stdout/stderr → `outputFile`에 스트리밍 저장
4. 완료 시 status 업데이트 + 알림

**출력 읽기:**  
`TaskOutputTool`이 `outputOffset`을 추적해 이전에 읽은 부분을 건너뛴다.  
파일을 직접 읽어 새로운 부분만 반환한다.

## LocalAgentTask — 로컬 에이전트 태스크

`tasks/LocalAgentTask/LocalAgentTask.tsx`는 `AgentTool`이 생성하는 인프로세스 에이전트다.

### 상태 구조

```typescript
type LocalAgentTaskState = TaskStateBase & {
  type: 'local_agent'
  isBackgrounded: boolean        // 백그라운드 전환 여부
  messages: Message[]            // 에이전트 대화 히스토리 (UI 표시용)
  progress: AgentProgress        // 도구 사용 횟수, 토큰, 최근 활동
  agentId: AgentId
  agentName?: string
  agentColor?: AgentColorName
  agentDefinition?: AgentDefinition
}
```

### ProgressTracker — 진행 추적

```typescript
type ProgressTracker = {
  toolUseCount: number            // 총 도구 사용 횟수
  latestInputTokens: number       // 최신 입력 토큰 (누적, 최신값 유지)
  cumulativeOutputTokens: number  // 출력 토큰 (턴별 합산)
  recentActivities: ToolActivity[] // 최근 5개 활동 (MAX_RECENT_ACTIVITIES)
}
```

API에서 `input_tokens`는 누적 값이라 최신값만 유지하고,  
`output_tokens`는 턴별 값이라 누적 합산한다.

## RemoteAgentTask — 원격 에이전트 태스크

`tasks/RemoteAgentTask/`는 별도 프로세스로 포크된 에이전트를 관리한다.

- `forkSubagent.ts`로 자식 프로세스 생성
- IPC 채널로 메시지/상태 동기화
- 더 큰 메모리 격리 (장시간 실행 에이전트에 적합)

---

## InProcessTeammateTask — 팀메이트 태스크

`tasks/InProcessTeammateTask/`는 `TeamCreateTool`이 생성하는 협업 에이전트다.

```typescript
type InProcessTeammateTaskState = TaskStateBase & {
  type: 'in_process_teammate'
  agentId: AgentId
  name: string                   // SendMessageTool이 name으로 라우팅
  mailbox: Message[]             // 수신된 메시지 큐
  isBackgrounded: boolean
}
```

**메일박스 통신:**  
`SendMessageTool` → `agentNameRegistry`에서 `AgentId` 조회  
→ `teammateMailbox.ts`로 메시지 전달 → 팀메이트의 다음 턴에서 처리

## DreamTask — 자동 메모리 통합 태스크

`tasks/DreamTask/DreamTask.ts`는 백그라운드에서 메모리를 통합하는 특수 태스크다.

```typescript
type DreamTaskState = TaskStateBase & {
  type: 'dream'
  phase: 'starting' | 'updating'  // 편집 도구가 처음 등장하면 'updating'으로 전환
  sessionsReviewing: number
  filesTouched: string[]           // 수정된 파일 (불완전 — 도구 호출 기반)
  turns: DreamTurn[]               // 최근 30턴 (MAX_TURNS) 대화 기록
  abortController?: AbortController
  priorMtime: number               // 잠금 파일 mtime (kill 시 롤백용)
}
```

Dream 에이전트는 4단계 구조로 동작한다:
1. **orient** — 현재 메모리 구조 파악
2. **gather** — 최근 세션 내용 수집
3. **consolidate** — 메모리 통합
4. **prune** — 오래된 메모리 정리

## BackgroundTask 표시

태스크는 하단 상태바의 "백그라운드 작업" 필(pill)에 표시된다.

```typescript
// 표시 조건 (tasks/types.ts)
function isBackgroundTask(task: TaskState): boolean {
  if (task.status !== 'running' && task.status !== 'pending') return false
  if ('isBackgrounded' in task && task.isBackgrounded === false) return false
  return true
}
```

`isBackgrounded = false`는 "아직 포그라운드에 있음"을 의미한다.  
AgentTool이 실행을 시작하면 `isBackgrounded = true`로 전환된다.
