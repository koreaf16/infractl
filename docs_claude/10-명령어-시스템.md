# 명령어 시스템 (슬래시 커맨드)

## 개요

슬래시 커맨드(`/commit`, `/compact` 등)는 사용자가 입력창에서 직접 호출하는  
대화형 명령이다. Claude API 호출 없이 즉시 실행된다.

---

## 커맨드 등록 (commands.ts)

`getCommands()`가 전체 커맨드 목록을 반환한다.

### 항상 등록되는 커맨드

```typescript
// commands.ts에서 직접 import
addDir, clear, color, commit, compact, config, context,
cost, diff, doctor, feedback, help, ide, init, keybindings,
login, logout, mcp, memory, mobile, rename, resume, review,
session, share, skills, status, tasks, teleport, terminalSetup,
theme, usage, vim, ...
```

### Feature-gated 커맨드

| 플래그 | 커맨드 |
|--------|--------|
| `PROACTIVE` / `KAIROS` | `proactive` |
| `KAIROS` | `brief`, `assistant` |
| `BRIDGE_MODE` | `bridge` |
| `VOICE_MODE` | `voice` |
| `KAIROS` / `KAIROS_PUSH_NOTIFICATION` | `alert` |
| `USER_TYPE=ant` | `agents-platform`, `autofix-pr`, `backfill-sessions` 등 |

## Command 타입

`types/command.ts`에 정의된 커맨드 유형:

```typescript
type Command =
  | LocalCommand      // 로컬 로직 실행 (JSX 렌더링 포함)
  | PromptCommand     // 프롬프트를 Claude에게 전송
  | LocalJSXCommand   // JSX UI 컴포넌트 렌더링

type LocalCommand = {
  type: 'local'
  name: string
  description: string
  isEnabled?: () => boolean
  isHidden?: boolean
  aliases?: string[]
  handler: (args, context) => Promise<void | JSX | LocalCommandResult>
}

type PromptCommand = {
  type: 'prompt'
  name: string
  description: string
  prompt: string        // Claude에게 전송할 텍스트
  tools?: string[]      // 사용 가능한 도구 제한
  model?: string        // 모델 오버라이드
}
```

### 세션 관리

| 커맨드 | 역할 |
|--------|------|
| `/resume` | 이전 세션 복원 (대화 목록 표시) |

| `/session` | 세션 정보 표시 |

### Git / PR

| 커맨드 | 역할 |
|--------|------|
| `/commit` | 스테이징된 변경 사항 커밋 |

| `/review` | 코드 리뷰 (PR 또는 diff 기반) |

## 커맨드 처리 흐름

```
사용자 입력: "/compact 요약해줘"
    │
    ├─ isSlashCommand() → true
    ├─ 커맨드 이름 파싱: "compact"
    ├─ 인자 파싱: "요약해줘"
    │
    ├─ getCommandsByMaxPriority() → 매칭 커맨드 찾기
    │       (로컬 커맨드 > MCP 커맨드 > 스킬 커맨드)
    │
    ├─ LocalCommand: handler() 직접 실행
    │       → UI 컴포넌트 렌더링 또는 로컬 로직 수행
    │
    └─ PromptCommand: 프롬프트를 사용자 메시지로 변환
            → QueryEngine에 주입 → Claude API 호출
```

## 커맨드 우선순위

같은 이름의 커맨드가 여러 소스에 있을 때:

```
1. 로컬 커맨드 (commands.ts 직접 등록)   ← 최고 우선순위
2. MCP 서버 커맨드
3. 플러그인 커맨드
4. 스킬 커맨드 (loadSkillsDir)           ← 최저 우선순위
```

## 특수 커맨드 상세

### /ultraplan (ultraplan.tsx)

복잡한 작업을 단계별 계획으로 분해하는 명령.

```typescript
// commands/ultraplan.tsx
// 1. 현재 요청 분석
// 2. 작업 단계 목록 생성
// 3. 계획을 EnterPlanMode와 함께 제시
// 4. 사용자 승인 후 단계별 실행
```

### /memory

메모리 파일을 직접 편집하거나 확인한다.

```
/memory                → MEMORY.md 내용 표시
/memory edit           → 메모리 파일 편집기 실행
/memory list           → 메모리 파일 목록
```

### /context

현재 컨텍스트 창 사용량과 시스템 프롬프트를 표시한다.

## 원격 모드에서의 커맨드 필터링

Bridge/원격 모드에서는 일부 커맨드가 비활성화된다.

```typescript
// commands.ts
filterCommandsForRemoteMode(commands)
// → /bridge, /voice 등 로컬 전용 커맨드 제거
```
