# 보조 시스템

## 1. Vim 모드

`vim/` 디렉토리가 Vim 스타일 키바인딩을 터미널 입력에 구현한다.

### 파일 구조

| 파일 | 역할 |
|------|------|
| `transitions.ts` | Normal ↔ Insert ↔ Visual 모드 전환 |
| `motions.ts` | 커서 이동 (h/j/k/l, w/b, 0/$, gg/G 등) |
| `operators.ts` | 편집 연산 (d, c, y, p 등) |
| `textObjects.ts` | 텍스트 객체 (iw, aw, i", a' 등) |
| `types.ts` | Vim 상태 타입 정의 |

### 동작 방식

```typescript
// /vim 커맨드로 활성화
// AppState에 vimMode: 'normal' | 'insert' | 'visual' 저장
// PromptInput에서 키 입력을 가로채 Vim 동작으로 처리

// 예: Normal 모드에서 'dd' → 현재 줄 삭제
// 예: Normal 모드에서 'i' → Insert 모드 전환
```

## 2. 키바인딩 시스템

`keybindings/` 디렉토리가 사용자 정의 키바인딩을 관리한다.

### 핵심 파일

| 파일 | 역할 |
|------|------|
| `defaultBindings.ts` | 기본 키바인딩 정의 |
| `resolver.ts` | 입력 키 → 액션 매핑 |
| `parser.ts` | 키 조합 파싱 (ctrl+s, alt+enter 등) |
| `match.ts` | 키 이벤트 매칭 |
| `loadUserBindings.ts` | `~/.claude/keybindings.json` 로드 |
| `schema.ts` | 키바인딩 스키마 검증 (Zod) |

### 코드 바인딩 형식

```json
// ~/.claude/keybindings.json
{
  "submit": "ctrl+enter",
  "newline": "enter",
  "history-up": "ctrl+p",
  "history-down": "ctrl+n",
  "interrupt": "ctrl+c"
}
```

### 코드 바인딩 선택 (KeybindingContext.tsx)

```typescript
// keybindings/KeybindingContext.tsx
// React Context로 현재 키바인딩 설정을 전체 컴포넌트에 제공
// PromptInput이 키 이벤트를 수신해 resolver.ts로 매핑
```

## 3. 테마 시스템

`utils/theme.ts`가 터미널 색상 테마를 관리한다.

### 테마 타입

```typescript
type ThemeName = 
  | 'dark'    // 기본 다크 테마
  | 'light'   // 라이트 테마
  | 'solarized-dark'
  | 'solarized-light'
  | 'custom'  // 사용자 정의

type Theme = {
  text: string            // 기본 텍스트
  planMode: string        // 계획 모드 강조
  permission: string      // 권한 요청
  autoAccept: string      // 자동 수락
  error: string           // 오류
  warning: string         // 경고
  info: string            // 정보
  success: string         // 성공
  // chalk 색상 값 (hex, rgb, named 등)
}
```

### 자동 테마 감지

```typescript
// utils/systemTheme.ts
resolveThemeSetting()
// → 'auto' 설정 시 터미널 배경 색상 감지
// → 어두운 배경 → dark, 밝은 배경 → light
```

## 5. Cron 스케줄러

백그라운드에서 주기적으로 프롬프트를 실행하는 스케줄러.

### Cron 태스크 정의

```typescript
// utils/cronTasks.ts
type CronTask = {
  id: string
  schedule: string      // cron 표현식 또는 'once'
  prompt: string        // 실행할 프롬프트
  enabled: boolean
  lastRun?: number
  nextRun?: number
}
```

저장 위치: `.claude/scheduled_tasks.json`

### 스케줄러 동작

```typescript
// utils/cronScheduler.ts
// CHECK_INTERVAL_MS = 1000ms (1초마다 확인)
// FILE_STABILITY_MS = 300ms (파일 안정화 대기)

// 파일 감시 (chokidar) → 변경 시 즉시 재로드
// 잠금 파일 경쟁 (cronTasksLock.ts):
//   → 멀티 세션에서 하나만 스케줄러 실행
//   → 소유 세션 충돌 시 다른 세션이 인계

// 지터(jitter) 추가: 정확한 시각에 집중 실행 방지
jitteredNextCronRunMs(task, jitterConfig)
```

### CronCreate/Delete/List 도구

```typescript
// feature('AGENT_TRIGGERS') 활성 시 사용 가능
CronCreateTool.call({
  schedule: '0 9 * * 1-5',  // 평일 오전 9시
  prompt: '오늘의 할일 목록 작성',
  name: 'daily-tasks',
})
```
