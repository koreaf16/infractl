# 시작점과 부트스트랩

## 진입점 구조

Claude Code CLI는 단일 바이너리지만, 목적에 따라 여러 진입점으로 분기한다.

```
entrypoints/cli.tsx   ← 최초 진입 (Bun 번들 엔트리)
    │
    ├── --version / -v         → 버전 출력 후 즉시 종료 (zero imports)
    ├── --dump-system-prompt   → 시스템 프롬프트 출력 후 종료 (내부 전용)
    ├── --claude-in-chrome-mcp → Chrome MCP 서버 실행
    ├── --chrome-native-host   → Chrome 네이티브 호스트 실행
    │
    └── main.tsx               ← 일반 실행 경로
```

---

## cli.tsx — Fast-path 최적화

`entrypoints/cli.tsx`는 무거운 모듈 로딩을 최소화하기 위해 설계되었다.

**핵심 특징:**
1. `--version` 처리는 `dynamic import` 없이 `MACRO.VERSION` (빌드 시 인라인)만 사용 → 0ms
2. 다른 모든 경로는 `await import()`로 지연 로딩
3. `startupProfiler`를 가장 먼저 로드해 체크포인트 측정 시작

```typescript
// 환경별 사전 설정 (임포트 전에 실행)
process.env.COREPACK_ENABLE_AUTO_PIN = '0'

// 원격 환경(CCR)에서 힙 크기 확장
if (process.env.CLAUDE_CODE_REMOTE === 'true') {
  process.env.NODE_OPTIONS = '--max-old-space-size=8192'
}

// ABLATION_BASELINE: A/B 테스트 비활성화 플래그 세트 일괄 적용
if (feature('ABLATION_BASELINE') && process.env.CLAUDE_CODE_ABLATION_BASELINE) {
  // DISABLE_BACKGROUND_TASKS, DISABLE_COMPACT 등 7개 플래그를 '1'로 설정
}
```

## main.tsx — 초기화 순서

`main.tsx`는 808KB의 대형 파일로, CLI 전체 초기화를 담당한다.

### 1단계: 병렬 프리패치 (최상위, import 평가 시점)

```typescript
// 임포트 순서가 곧 실행 순서 — 병렬 실행을 위해 최상단에 배치
profileCheckpoint('main_tsx_entry')
startMdmRawRead()          // MDM 정책 읽기 (subprocess, 병렬)
startKeychainPrefetch()    // macOS Keychain OAuth 토큰 프리패치 (병렬)
```

### 2단계: Commander.js 옵션 파싱

| 옵션 | 역할 |
|------|------|
| `-p, --print` | Headless 모드 (단일 쿼리) |
| `--model` | 모델 오버라이드 |
| `--permission-mode` | 권한 모드 설정 |
| `--worktree` | Git worktree 격리 세션 |
| `--resume` | 이전 세션 복원 |
| `--agent` | 에이전트 정의 지정 |
| `--mcp-server` | MCP 서버 설정 추가 |

### 3단계: init() 호출 (entrypoints/init.ts)

```typescript
await init(
  apiKey,
  dangerouslySkipPermissions,
  printMode,
  customSystemPrompt,
  // ...
)
```

`init()`이 수행하는 작업:
- 인증 확인 (API 키 / OAuth 토큰 유효성)
- 신뢰 다이얼로그 표시 (최초 실행 시)
- MDM 정책 적용
- 원격 관리 설정 로드
- GrowthBook(Feature Flag) 초기화
- 텔레메트리 초기화

### 4단계: setup() 호출 (setup.ts)

```typescript
await setup(cwd, permissionMode, allowDangerouslySkipPermissions, ...)
```

`setup()`이 수행하는 작업:
- Node.js 버전 확인 (>= 18 필요)
- git root 탐색 (`findGitRoot()`)
- `projectRoot` 설정 (`bootstrap/state.ts`)
- `sessionId` 생성
- worktree 생성 (--worktree 시)
- 세션 메모리 초기화 (`initSessionMemory()`)
- 훅 설정 스냅샷 캡처 (`captureHooksConfigSnapshot()`)

### 5단계: MCP 및 도구 초기화

```typescript
const { tools, commands, resources } = await getMcpToolsCommandsAndResources(...)
const allTools = [...getTools(), ...tools]
```

- 내장 도구 45+ 로드 (`getTools()`)
- MCP 서버 연결 및 도구 동적 추가
- 플러그인/스킬 초기화

### 6단계: Ink 렌더링 시작

```typescript
await renderAndRun(<REPL ... />, options)
// 또는 headless 모드:
await runQuery(query, tools, ...)
```

## bootstrap/state.ts — 전역 부트스트랩 상태

`bootstrap/state.ts`는 프로세스 전체에서 공유되는 **불변 전역 상태**를 관리한다.  
React 상태(`AppState`)와 달리, 이 값들은 초기화 후 변경되지 않는다.

주요 값:

| 함수 | 역할 |
|------|------|
| `getSessionId()` | 현재 세션 UUID |
| `getProjectRoot()` | 감지된 git root (또는 cwd) |
| `getOriginalCwd()` | 프로세스 시작 시 cwd |
| `setIsRemoteMode()` | 원격 모드 플래그 |
| `setMainLoopModelOverride()` | CLI 모델 오버라이드 |
| `setAdditionalDirectoriesForClaudeMd()` | CLAUDE.md 추가 탐색 경로 |
| `switchSession()` | 세션 전환 (resume 시) |

## 시작 프로파일링

`utils/startupProfiler.ts`는 각 단계의 소요 시간을 측정한다.

```typescript
profileCheckpoint('cli_entry')      // cli.tsx 진입
profileCheckpoint('main_tsx_entry') // main.tsx 평가 시작
profileCheckpoint('init_done')      // init() 완료
profileCheckpoint('setup_done')     // setup() 완료
profileReport()                     // --verbose 시 출력
```

## 기타 진입점

### entrypoints/init.ts
`claude init` 명령 전용. CLAUDE.md 생성 보조, 온보딩 흐름 처리.

### entrypoints/mcp.ts
`--mcp-server` 플래그 시 활성화. Claude Code 자체를 MCP 서버로 노출한다.  
외부 IDE나 도구가 Claude를 MCP 도구로 호출할 수 있게 한다.

### entrypoints/sdk/
`entrypoints/sdk/coreSchemas.ts`에서 스키마를 정의하며, 프로그래밍 방식으로  
Claude Code를 라이브러리처럼 사용할 때 진입한다.
