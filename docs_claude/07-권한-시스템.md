# 권한 시스템

## 개요

Claude Code의 권한 시스템은 도구 실행 전 다층 검사를 수행해  
의도치 않은 파일 수정이나 위험한 명령 실행을 방지한다.

---

## PermissionMode — 권한 모드

`types/permissions.ts`에 정의된 전체 모드:

| 모드 | 설명 | 동작 |
|------|------|------|
| `default` | 기본 모드 | 변경 전 사용자 확인 |
| `plan` | 계획 모드 | 읽기 전용만 허용, 쓰기 시 확인 |
| `acceptEdits` | 편집 자동 수락 | 파일 편집은 자동, Bash는 확인 |
| `bypassPermissions` | 권한 우회 | 모든 도구 자동 허용 (위험) |
| `dontAsk` | 묻지 않음 | 거부 대신 오류 반환 |
| `auto` | 자동 모드 (내부용) | 트랜스크립트 분류기 기반 자동 결정 |

**주의:** `bypassPermissions`는 `--dangerously-skip-permissions` 플래그로만 활성화.

## 권한 결정 흐름

```
tool.checkPermissions(input, context)
    │
    ├─ 1. alwaysDenyRules 확인 → 매칭 시 즉시 Deny
    ├─ 2. alwaysAllowRules 확인 → 매칭 시 즉시 Allow
    ├─ 3. bypassPermissions/acceptEdits 모드 → Allow
    ├─ 4. plan 모드 + 쓰기 도구 → Deny
    ├─ 5. 도구별 커스텀 검사 (BashTool은 보안 파이프라인)
    ├─ 6. dontAsk 모드 → Ask가 필요하면 Deny
    └─ 7. 사용자에게 Ask → 다이얼로그 표시 후 대기
```

### PermissionResult 타입

```typescript
type PermissionResult =
  | { type: 'allow'; reason?: string }
  | { type: 'deny'; reason: string; errorCode?: number }
  | { type: 'ask'; prompt: string; tool: Tool }
```

## 권한 규칙 (PermissionRule)

사용자가 설정한 항상 허용/거부/질문 규칙.

```typescript
type PermissionRule = {
  toolName: string        // 도구 이름 (예: 'Bash', 'Write')
  ruleValue: string       // 매칭 패턴 (예: 'Bash(git:*)', '*.ts')
  behavior: 'allow' | 'deny' | 'ask'
}
```

**규칙 소스 (`PermissionRuleSource`):**
- `local` — 현재 프로젝트 설정 (`.claude/settings.local.json`)
- `project` — 프로젝트 설정 (`settings.json`)
- `user` — 사용자 전역 설정 (`~/.claude/settings.json`)
- `managed` — MDM/기업 정책 (읽기 전용)

### 규칙 파싱

```typescript
// utils/permissions/permissionRuleParser.ts
// "Bash(git:*)" → { toolName: 'Bash', pattern: 'git:*' }
// "Write(*.ts)" → { toolName: 'Write', pattern: '*.ts' }
permissionRuleValueFromString('Bash(git:*)')
```

## 파일시스템 권한 (filesystem.ts)

파일 접근 권한을 결정하는 핵심 로직.

### 허용 경로

1. **projectRoot** 및 하위 경로
2. **additionalWorkingDirectories** (설정으로 추가)
3. **스크래치패드** (`~/.claude/scratchpad/<sessionId>/`)
4. **tmpdir** 내 Claude 전용 경로

### 금지 경로

```typescript
export const DANGEROUS_FILES = [
  '.gitconfig',
  '.gitmodules',
  '.bashrc',
  '.bash_profile',
  '.zshrc',
  '.profile',
  // ssh 키, 자격증명 파일 등
]
```

### 경로 검증 체크

1. **경로 순회 공격** 방지: `..` 패턴 탐지 (`containsPathTraversal()`)
2. **UNC 경로** (Windows) 위험 패턴 (`containsVulnerableUncPath()`)
3. **심볼릭 링크** 확인: 실제 경로가 허용 디렉토리 내인지
4. **CLAUDE.md 보호**: `.claude/CLAUDE.md` 편집은 특별 패턴으로만 허용

## BashTool 보안 파이프라인

```
bashSecurity.ts — validateDangerousPatterns()
    │
    ├─ COMMAND_SUBSTITUTION_PATTERNS 검사
    │   → $(), ${}, <(), >(), =cmd (Zsh), ~[]
    │
    ├─ ZSH_DANGEROUS_COMMANDS 검사
    │   → zmodload, emulate, sysopen, sysread, syswrite 등
    │
    ├─ 백틱 명령 치환 검사 (이스케이프 여부 구분)
    └─ heredoc 내 명령 치환 탐지 ($( << 패턴)

pathValidation.ts — 실행 명령의 파일 인자 경로 검증

readOnlyValidation.ts — 읽기 전용 명령 판별
    → cat, ls, find, grep, git log 등은 읽기 전용으로 분류

bashPermissions.ts — 권한 규칙 적용 + 분류기 호출
    → alwaysAllow/alwaysDeny 규칙 매칭
    → TRANSCRIPT_CLASSIFIER feature 시 자동 모드 분류기 호출
```

## 샌드박스 (sandbox-adapter.ts)

일부 환경에서 Bash 명령을 격리된 샌드박스에서 실행한다.

```typescript
// shouldUseSandbox.ts
// macOS Seatbelt, Linux seccomp 등
shouldUseSandbox(command, context)
// → 'seatbelt' | 'seccomp' | null

// sandbox-adapter.ts
SandboxManager.execute(command, sandboxType)
```

샌드박스 적용 조건:
- 네트워크 접근이 불필요한 명령
- 파일시스템 쓰기가 없는 명령
- 환경 변수에 `CLAUDE_CODE_USE_SANDBOX=1`

## Auto 모드 분류기 (TRANSCRIPT_CLASSIFIER)

내부 전용 feature. 트랜스크립트를 분석해 도구 실행을 자동으로 허용/거부한다.

```typescript
// utils/permissions/classifierDecision.ts (feature flag으로 조건부 로드)
// 대화 히스토리를 보고 현재 작업의 안전성 판단
// → 안전하다고 판단하면 auto-allow
// → 불확실하면 사용자에게 ask
```

## 권한 대화상자 (components/permissions/)

사용자에게 권한을 요청하는 UI 컴포넌트들.

```
components/permissions/
  PermissionDialog.tsx       ← 기본 권한 요청 다이얼로그
  BashPermissionDialog.tsx   ← Bash 명령 전용
  FilePermissionDialog.tsx   ← 파일 편집 전용
  ManagedSettingsSecurityDialog.tsx ← 기업 정책 설명
```

**Ask 결정 처리 흐름:**
1. `checkPermissions()` → `{ type: 'ask' }` 반환
2. `setToolJSX()` 로 다이얼로그 렌더링
3. 사용자 선택 대기 (AbortController로 취소 가능)
4. 선택 결과 → `PermissionUpdate` → 설정 파일에 영구 저장 (선택 시)
