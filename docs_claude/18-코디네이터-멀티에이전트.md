# 코디네이터와 멀티에이전트

## 개요

Claude Code의 멀티에이전트 시스템은 두 가지 모드로 동작한다.

| 모드 | 구현 | 용도 |
|------|------|------|
| **Coordinator Mode** | `coordinator/` | 작업을 분해해 여러 워커 에이전트에 분배 |
| **Swarm Mode** | `TeamCreateTool` + 메일박스 | 팀메이트 에이전트들이 협업 |

---

## Coordinator Mode (coordinatorMode.ts)

`CLAUDE_CODE_COORDINATOR_MODE=1` 환경변수로 활성화.

```typescript
// coordinator/coordinatorMode.ts
isCoordinatorMode()
// → process.env.CLAUDE_CODE_COORDINATOR_MODE 확인
// → feature('COORDINATOR_MODE') 플래그 필요

matchSessionMode(sessionMode)
// 재개(resume) 시 세션의 모드와 현재 모드를 맞춤
// 불일치 시 경고 메시지 반환
```

### 코디네이터 도구 필터링

코디네이터 에이전트는 제한된 도구 집합만 사용한다.

```typescript
// constants/tools.ts
COORDINATOR_MODE_ALLOWED_TOOLS = [
  'Agent',          // 워커 에이전트 생성
  'Bash',           // 직접 쉘 실행 (읽기 전용)
  'Read',
  'Glob',
  'Grep',
  'TeamCreate',     // 팀메이트 생성
  'TeamDelete',
  'SendMessage',    // 팀메이트에게 메시지
  'TaskOutput',
  'TaskStop',
]
// → 파일 쓰기, 편집 등 직접 수정 도구는 워커에게 위임
```

### 코디네이터 사용자 컨텍스트

```typescript
getCoordinatorUserContext(mcpClients, scratchpadDir)
// → 시스템 프롬프트에 코디네이터 역할 지시문 추가
// → 스크래치패드 디렉토리 정보 주입
// → 에이전트 간 협업 가이드라인 포함
```

## AgentId 체계

`types/ids.ts`에서 브랜드 타입으로 AgentId를 관리한다.

```typescript
type AgentId = UUID & { readonly __brand: 'AgentId' }
type SessionId = UUID & { readonly __brand: 'SessionId' }

asAgentId(uuid)    // UUID → AgentId 변환
asSessionId(uuid)  // UUID → SessionId 변환
```

모든 에이전트(메인 스레드 포함)는 고유한 AgentId를 가진다.

## InProcessTeammateTask — 협업 에이전트

`TeamCreateTool`이 같은 프로세스 내에 새 에이전트를 생성한다.

```typescript
// TeamCreateTool.call({ name: "reviewer", system: "코드 리뷰 전문가" })
// → InProcessTeammateTask 생성
// → agentNameRegistry에 name → AgentId 등록
// → AppState.tasks에 추가
```

**팀메이트 격리:**
- 독립적인 메시지 히스토리
- 독립적인 파일 상태 캐시
- 독립적인 AbortController
- 공유: AppState (태스크 조회/업데이트에 한정)

## 메일박스 통신 (teammateMailbox.ts)

팀메이트 간 메시지 전달 시스템.

```typescript
// utils/teammateMailbox.ts

// 메시지 전송
sendToTeammate(agentId, message, setAppState)
// → InProcessTeammateTaskState.mailbox에 추가

// 메시지 수신 (팀메이트 실행 루프에서)
drainMailbox(taskId, getAppState)
// → mailbox 큐에서 메시지를 모두 꺼내 반환
// → 꺼낸 후 mailbox 비움
```

**SendMessageTool 흐름:**

```
SendMessageTool.call({ to: "reviewer", message: "..." })
    │
    ├─ agentNameRegistry에서 "reviewer" → AgentId 조회
    └─ sendToTeammate(agentId, message)
            │
            └─ InProcessTeammateTask 루프에서 mailbox 확인
                    └─ 새 메시지 → 다음 쿼리 턴에 user 메시지로 주입
```

## 포크된 에이전트 (forkedAgent.ts)

별도 프로세스에서 에이전트를 실행하는 방식.

```typescript
// utils/forkedAgent.ts
createSubagentContext(parentContext)
// → 독립적인 ToolUseContext 생성
// → setAppState: 루트 스토어의 tasks에만 접근
// (부모의 메시지 히스토리와 독립)

type CacheSafeParams = {
  // 프롬프트 캐시 공유를 위해 부모와 동일한 파라미터
  model: string
  systemPrompt: string[]
  tools: Tools
}
```
