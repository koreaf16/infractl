# Claude Code CLI — 전체 아키텍처 개요

## 기술 스택

| 항목 | 기술 |
|------|------|
| 언어 | TypeScript (strict) |
| UI 렌더링 | React + Ink (터미널 기반) |
| 런타임 | Bun (번들러 겸 실행기) |
| AI SDK | `@anthropic-ai/sdk` |
| 프로토콜 | MCP (`@modelcontextprotocol/sdk`) |
| 스키마 | Zod |
| 로깅 | 구조화 로그 (자체 구현) |

## 실행 모드

| 모드 | 설명 | 진입 조건 |
|------|------|-----------|
| **Interactive REPL** | 기본 터미널 대화 모드 | 기본값 |
| **Headless** | `-p` 플래그로 단일 쿼리 실행 후 종료 | `--print` / `-p` |
| **SDK** | 프로그래밍 방식 API 호출 | `entrypoints/sdk/` |
| **MCP Server** | MCP 서버로 동작 | `--mcp-server` |
| **Bridge** | claude.ai와 실시간 연결 | `/remote-control` |
| **Coordinator** | 멀티에이전트 오케스트레이션 | `feature('COORDINATOR_MODE')` |
| **Kairos** | 어시스턴트 모드 | `feature('KAIROS')` |
| **Dream** | 백그라운드 추론 (cron/자동) | DreamTask |
| **Worktree** | 격리된 git worktree 세션 | `--worktree` |

## 전체 데이터 흐름

```
사용자 입력
    │
    ▼
PromptInput (React/Ink UI)
    │
    ▼
QueryEngine.processUserInput()
    │
    ├── 시스템 프롬프트 조립 (constants/prompts.ts)
    ├── 컨텍스트 생성 (context.ts: git status, CLAUDE.md, 환경정보)
    │
    ▼
query.ts — Claude API 스트리밍 호출 (@anthropic-ai/sdk)
    │
    ▼
응답 스트리밍 처리
    ├── text_delta → AssistantMessage 업데이트
    └── tool_use → 도구 실행 루프
            │
            ▼
        Tool.execute() — 권한 검사 → 도구 로직 수행
            │
            ▼
        ToolResult → API 재전송 (루프 반복)
    │
    ▼
최종 AssistantMessage → UI 렌더링
    └── AppState 업데이트 → React 리렌더링
```

## Feature Flag 시스템

`bun:bundle`의 `feature()` 함수로 빌드 시점에 죽은 코드를 제거한다.

```typescript
// 조건부 모듈 로딩 — 외부 빌드에서는 coordinatorModeModule이 null
const coordinatorModeModule = feature('COORDINATOR_MODE')
  ? require('./coordinator/coordinatorMode.js')
  : null;
```

주요 플래그:
- `COORDINATOR_MODE` — 멀티에이전트 코디네이터 활성화
- `KAIROS` — 어시스턴트 모드 활성화
- `ABLATION_BASELINE` — A/B 테스트 기준선 비활성화 세트
- `DUMP_SYSTEM_PROMPT` — 내부 시스템 프롬프트 덤프 도구
- `ENABLE_AGENT_SWARMS` — 에이전트 군집 기능

## 주요 타입 관계

```
AppState
  ├── messages: Message[]          (대화 히스토리)
  ├── tasks: { [id]: TaskState }   (백그라운드 태스크)
  ├── mcp.tools: Tool[]            (MCP 도구 목록)
  ├── toolPermissionContext        (권한 컨텍스트)
  ├── plugins                      (플러그인 상태)
  └── settings: SettingsJson       (설정)

Tool
  ├── name, description, inputSchema
  ├── isEnabled(context): boolean  (활성화 조건)
  ├── checkPermissions(ctx): PermissionResult
  └── call(input, ctx): Promise<ToolResult>

Task
  ├── id: string                   (prefix + 8자 랜덤)
  ├── type: TaskType               (local_bash | local_agent | dream | ...)
  ├── status: TaskStatus           (pending → running → completed/failed/killed)
  └── outputFile: string           (디스크 출력 경로)
```
